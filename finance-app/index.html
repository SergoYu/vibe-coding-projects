Аномальные месяцы

    Качество модели

    Прогноз — это оценка по прошлой динамике, а не гарантия. Модель не знает о будущих событиях (новые цены, сезон, крупные заказы). Решение принимает человек.

    Как это работает

    Прибыль
    Прибыль = Выручка − Переменные затраты − Постоянные затраты. Если результат отрицательный, это убыток.
    Рентабельность продаж
    Рентабельность продаж показывает долю прибыли в выручке. Рентабельность = Прибыль / Выручка × 100%. При нулевой выручке показатель не определяется.
    Суммарные затраты
    Суммарные затраты = Переменные затраты + Постоянные затраты. На диаграмме они сравниваются с выручкой.
    ИИ-прогноз
    Модель машинного обучения (линейная регрессия по времени) обучается на ваших данных: находит тренд выручки, затрат и прибыли и продлевает его на 3 месяца. Диапазон 95% показывает, насколько прогноз может отклониться.
    Аномалии
    Месяц считается аномальным, если значение сильно выбивается из тренда (модифицированный z-показатель больше 3,5). Такие месяцы исключаются из обучения, чтобы разовое событие не исказило прогноз.
    Проверка качества
    Модель обучают без последних 3 месяцев и сравнивают её прогноз с фактом. Средняя ошибка в процентах (MAPE) показывает, насколько можно доверять прогнозу.

    Учебный проект. Калькулятор использует упрощённую модель и не заменяет бухгалтерский и налоговый расчёт. Прогноз носит справочный характер.
